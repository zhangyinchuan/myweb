# 测试计划：个人网站 v1.0

## 执行摘要

- **测试对象**：个人综合网站（首页、博客、视频、书籍四大模块）
- **测试目标**：验证所有页面功能正确、响应式适配、ISR 内容更新、API 集成、性能达标
- **关键风险**：B站/YouTube 嵌入受网络环境影响；Strapi ISR Webhook 时序问题
- **测试周期**：上线前 3 天执行完整测试，上线后 1 天执行回归验证

---

## 测试范围

### 纳入范围
- 首页（Hero + 博客预览 + 视频预览）
- 博客列表页、详情页（含富文本渲染）
- 视频列表页、详情页（含 iframe 嵌入 + 降级）
- 书籍列表页、详情页（含读书笔记）
- 分类/标签筛选功能（URL 参数同步）
- ISR 内容更新（发布后 ≤60s 生效）
- 响应式适配（375px / 768px / 1280px）
- 深色模式切换
- 404 页面
- 安全响应头

### 排除范围
- Strapi Admin 后台 UI（Strapi 内部功能）
- 用户认证/注册（本项目不包含）
- 评论功能（未实现）
- 搜索功能（未实现）
- 性能压力测试（单人博客，流量有限）

## 准入条件（Entry Criteria）

- [ ] 代码部署到 Staging 环境
- [ ] Strapi CMS 已初始化并录入测试数据（≥3篇博客、3个视频、3本书）
- [ ] 环境变量配置完整（OSS、API Token 等）
- [ ] Next.js build 无报错

## 准出条件（Exit Criteria）

- [ ] 所有 P0 测试用例通过
- [ ] P1 测试用例通过率 ≥ 95%
- [ ] 无 Critical/High 级别未解决 Bug
- [ ] Lighthouse Performance ≥ 85
- [ ] 生产环境健康检查通过

---

## 风险评估

| 风险 | 概率 | 影响 | 缓解措施 |
|---|---|---|---|
| B站嵌入在国内被屏蔽 | 低 | 高 | 提供原始链接降级按钮 |
| YouTube 无法访问（国内） | 高 | 中 | 降级显示跳转链接 |
| OSS CDN 图片加载慢 | 低 | 中 | 配置图片 lazy loading + 占位符 |
| Strapi ISR Webhook 失败 | 中 | 低 | 60s 自动 revalidate 兜底 |
| 阿里云 ECS 内存不足 | 低 | 高 | 监控内存，PM2 max_memory_restart |
