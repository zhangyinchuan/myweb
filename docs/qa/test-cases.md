# 测试用例：个人网站 v1.0

> 格式：每个用例包含优先级、前置条件、步骤、预期结果、测试数据。

---

## 模块一：首页（HomePage）

### TC-HOME-001：首页正常加载
**优先级：** P0 | **类型：** 功能

**前置条件：** Strapi 已发布 ≥1 篇博客、≥1 个视频；全局配置已填写

**步骤：**
1. 打开 `https://staging.your-domain.com`
   **预期：** 页面在 3s 内完成首次内容绘制（LCP）；无控制台报错
2. 检查 Navbar
   **预期：** 站点名称显示正确；导航链接（首页/博客/视频/书籍）均可见
3. 检查 Hero 区
   **预期：** 显示站长头像、名字、一句话简介、社交链接图标
4. 检查「最新文章」区块
   **预期：** 显示 ≤6 张博客卡片，每张含标题、封面图、发布日期、分类
5. 检查「最新视频」区块
   **预期：** 显示 ≤6 张视频卡片，每张含标题、缩略图、平台标识（B站/YouTube）
6. 检查 Footer
   **预期：** 版权信息、导航链接、社交图标均显示

**测试数据：** 全局配置：siteName="测试站点"，tagline="测试简介"

---

### TC-HOME-002：首页无内容时降级显示
**优先级：** P1 | **类型：** 边界

**前置条件：** Strapi 中所有博客/视频均为 draft 状态

**步骤：**
1. 访问首页
   **预期：** 「最新文章」和「最新视频」区块隐藏，不显示空白区域或报错；Hero 区正常显示

---

### TC-HOME-003：首页卡片点击跳转
**优先级：** P0 | **类型：** 功能

**步骤：**
1. 点击任意博客卡片
   **预期：** 跳转到对应 `/blog/[slug]` 详情页，URL 正确
2. 返回首页，点击任意视频卡片
   **预期：** 跳转到对应 `/videos/[slug]` 详情页

## 模块二：博客

### TC-BLOG-001：博客列表页加载与分页
**优先级：** P0 | **类型：** 功能

**前置条件：** Strapi 已发布 ≥12 篇博客（可触发分页）

**步骤：**
1. 访问 `/blog`
   **预期：** 卡片网格显示，3 列（桌面）/ 2 列（平板）/ 1 列（手机）
2. 检查每张卡片
   **预期：** 含标题、封面图、摘要（≤3行截断）、发布日期、分类标签、阅读时长

---

### TC-BLOG-002：博客按分类筛选
**优先级：** P0 | **类型：** 功能

**前置条件：** 存在分类「技术」和「生活」，各有 ≥2 篇已发布博客

**步骤：**
1. 访问 `/blog`，点击分类「技术」
   **预期：** URL 变为 `/blog?category=tech`；只显示该分类文章；其他分类文章不可见
2. 点击「全部」
   **预期：** URL 恢复 `/blog`；所有文章显示
3. 点击分类「生活」
   **预期：** URL 变为 `/blog?category=life`；只显示生活分类文章

---

### TC-BLOG-003：博客按标签筛选
**优先级：** P0 | **类型：** 功能

**步骤：**
1. 点击标签「React」
   **预期：** URL 含 `?tag=react`；列表只显示含 React 标签的文章
2. 同时选中分类「技术」和标签「React」
   **预期：** URL 含 `?category=tech&tag=react`；结果为两个条件的交集

---

### TC-BLOG-004：博客详情页渲染
**优先级：** P0 | **类型：** 功能

**前置条件：** 存在一篇包含标题、正文（含 h2/h3/图片/代码块/列表/引用）、封面图、标签的已发布博客

**步骤：**
1. 点击博客卡片进入详情页
   **预期：** URL 为 `/blog/[slug]`；页面标题 = 文章标题
2. 检查文章头部
   **预期：** 分类（可点击）、发布日期、阅读时长均显示；标签列表显示
3. 检查封面图
   **预期：** 图片加载正常，尺寸适配，含 alt 属性
4. 检查富文本正文
   **预期：** h2/h3 标题层级正确；有序/无序列表格式正确；代码块等宽字体；引用块有左边框；图片居中显示
5. 点击「← 返回博客」
   **预期：** 返回 `/blog` 列表页

**测试数据：** 一篇含所有富文本元素的测试文章

---

### TC-BLOG-005：博客 404 处理
**优先级：** P1 | **类型：** 边界

**步骤：**
1. 访问 `/blog/non-existent-slug-12345`
   **预期：** 显示 404 页面，含「页面未找到」文案和「返回首页」按钮
2. 点击「返回首页」
   **预期：** 正确跳转到 `/`

## 模块五：ISR 内容更新

### TC-ISR-001：内容发布后页面自动更新
**优先级：** P1 | **类型：** 集成

**前置条件：** Strapi lifecycle webhook 已配置且 NEXTJS_REVALIDATE_TOKEN 正确

**步骤：**
1. 记录当前 `/blog` 列表页文章数量（假设为 N）
2. 在 Strapi Admin 中发布一篇新博客文章（标题「ISR 测试文章」）
3. 等待 ≤10 秒，刷新 `/blog` 列表页
   **预期：** 新文章出现在列表（文章数 = N+1）；无需手动重新部署

---

### TC-ISR-002：ISR revalidate API 安全验证
**优先级：** P1 | **类型：** 安全

**步骤：**
1. 发送请求：`POST /api/revalidate`，不带 Authorization header
   **预期：** 返回 401 Unauthorized
2. 发送请求：`POST /api/revalidate`，带错误 token
   **预期：** 返回 401 Unauthorized
3. 发送请求：带正确 token，body 为 `{"path": "/blog"}`
   **预期：** 返回 `{"revalidated": true, "path": "/blog"}`

## 模块六：响应式与 UI

### TC-UI-001：移动端（375px）响应式
**优先级：** P1 | **类型：** UI

**步骤：**
1. DevTools 设置视口 375×812，访问首页
   **预期：** 无横向滚动条；Hero 区竖排布局；卡片单列显示
2. 访问 `/blog`
   **预期：** FilterBar 可横向滚动；博客卡片单列
3. 访问博客详情页
   **预期：** 标题字号合理（≥20px）；图片不超出边界；代码块可横向滚动

---

### TC-UI-002：深色模式切换
**优先级：** P1 | **类型：** UI

**步骤：**
1. 系统切换为深色模式，刷新页面
   **预期：** 页面自动切换为深色主题（深灰背景、浅色文字）；刷新后保持
2. 切换回浅色模式
   **预期：** 页面恢复浅色主题；localStorage 中 `color-mode` 值更新

---

### TC-UI-003：页面性能（Lighthouse）
**优先级：** P1 | **类型：** 性能

**步骤：**
1. 在 Chrome DevTools Lighthouse 中对首页执行性能测试（移动端模式）
   **预期：** Performance ≥ 85；LCP < 2.5s；CLS < 0.1
2. 对博客详情页执行测试
   **预期：** Performance ≥ 85

---

### TC-UI-004：安全响应头
**优先级：** P1 | **类型：** 安全

**步骤：**
1. 使用 `curl -I https://staging.your-domain.com` 检查响应头
   **预期：** 包含以下所有头：
   - `X-Frame-Options: DENY`
   - `X-Content-Type-Options: nosniff`
   - `Strict-Transport-Security: max-age=...`
   - `X-XSS-Protection: 1; mode=block`

## 模块七：无障碍

### TC-A11Y-001：键盘导航
**优先级：** P2 | **类型：** 无障碍

**步骤：**
1. 不使用鼠标，仅用 Tab/Enter/Space 键浏览首页
   **预期：** 所有可点击元素（导航链接、卡片、标签）均可聚焦且有可见焦点环
2. 使用屏幕阅读器（VoiceOver/NVDA）访问博客详情页
   **预期：** 文章标题被正确读出；图片有 alt 文本；标签有 aria-pressed 属性

---

**注意：** WCAG 完整合规需配合无障碍专家进行人工审核，上述测试仅覆盖基础场景。
