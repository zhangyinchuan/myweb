# 个人网站 - 产品需求文档 (PRD)

## 需求描述

### 背景
- **业务问题**：需要一个综合型个人网站，用于展示个人品牌、分享博客文章、推荐视频内容和书籍笔记，面向普通大众访客
- **目标用户**：普通大众（对个人内容感兴趣的访客）
- **价值主张**：打造一个具有 Apple 式极简现代科技感的个人内容中心，通过博客、视频分享、书籍分享等模块持续输出有价值的内容

### 功能概览
- **核心功能**：
  - 首页：个人品牌展示 + 最新博客预览 + 最新视频分享
  - 博客：文章列表、详情页，支持标签/分类筛选
  - 视频分享：嵌入 B站/YouTube 视频，支持标签/分类筛选
  - 书籍分享：书单展示 + 读书笔记，支持标签/分类筛选
  - 后台内容管理：通过 Strapi Headless CMS 管理所有内容
- **功能边界（不包含）**：
  - 用户注册/登录系统
  - 评论功能
  - 搜索功能
  - 视频文件自托管
- **用户场景**：
  - 访客浏览首页，快速了解最新内容动态
  - 访客进入博客页，按分类浏览或筛选感兴趣的文章
  - 访客进入视频页，浏览推荐视频并直接观看（跳转B站/YouTube）
  - 访客进入书籍页，查看书单推荐并阅读读书笔记
  - 站长登录 Strapi 后台，发布/编辑博客、视频推荐、书籍笔记

### 详细需求

#### 首页
- Hero 区：个人头像 + 名字 + 一句话简介 + 社交媒体链接
- 最新博客预览区：展示最新 3-6 篇文章（标题、封面图、摘要、发布日期、分类标签）
- 最新视频分享区：展示最新 3-6 个视频推荐（缩略图、标题、来源平台图标）
- 页脚：版权信息 + 导航链接

#### 博客页
- 文章列表页：卡片式布局，显示封面图、标题、摘要、日期、标签
- 分类/标签筛选栏：支持按分类或标签过滤文章列表
- 文章详情页：标题、封面图、发布日期、正文（富文本/Markdown）、标签

#### 视频分享页
- 视频列表：卡片式布局，嵌入 B站/YouTube 视频播放器或显示缩略图+链接
- 分类/标签筛选栏
- 视频详情：标题、简介、嵌入播放器、标签

#### 书籍分享页
- 书单列表：卡片式布局，显示书籍封面、书名、作者、简评
- 分类/标签筛选栏
- 书籍详情页：封面、书名、作者、出版信息、读书笔记（富文本长文）、标签

#### 内容管理（Strapi 后台）
- 博客内容类型：标题、封面图、摘要、正文（富文本）、分类、标签、发布状态
- 视频内容类型：标题、视频URL（B站/YouTube）、缩略图、简介、分类、标签
- 书籍内容类型：书名、作者、封面图、简评、读书笔记（富文本）、分类、标签
- 全局内容类型：个人信息（头像、简介、社交链接）

## 设计决策

### 技术方案

#### 架构选择
采用 **Jamstack 全栈架构**：
- 前端：**Next.js 14**（App Router）+ **TypeScript** + **Tailwind CSS**
- 后端/CMS：**Strapi v4**（自托管 Headless CMS）
- 数据库：**PostgreSQL**（Strapi 默认支持）
- 部署：阿里云 ECS 服务器，使用 Nginx 反向代理 + PM2 进程管理

#### 关键组件
- `Next.js` — SSG/ISR 生成静态页面，SEO 友好，性能优异
- `Strapi` — 提供 REST API / GraphQL，后台内容管理界面
- `Tailwind CSS` — 实现 Apple 式极简现代科技感 UI
- `Framer Motion` — 页面过渡动画和微交互
- `next/image` — 图片优化
- `Nginx` — 反向代理，前端 + Strapi API 统一端口访问

#### 数据存储
- Strapi + PostgreSQL 存储所有内容数据
- 媒体文件（封面图、头像）存储于阿里云 OSS（通过 Strapi 媒体库对接）

#### 接口设计
- 前端通过 Strapi REST API 获取内容（`/api/posts`, `/api/videos`, `/api/books` 等）
- 使用 `ISR`（增量静态再生成）策略：内容更新后自动触发页面重新生成
- API 请求使用 `revalidate` 配置（博客/视频/书籍页面 revalidate 60 秒）

### 约束条件
- **性能要求**：首屏 LCP < 2.5s，页面切换流畅无明显卡顿
- **兼容性**：支持 Chrome、Safari、Firefox 最新两个大版本；移动端响应式适配
- **安全性**：Strapi 后台仅内网/VPN 访问，或设置强密码 + HTTPS
- **可扩展性**：内容类型设计预留扩展字段，后续可增加搜索、评论等功能

### 风险评估
- **技术风险**：Strapi 自托管维护成本较高 → 定期备份数据库，文档化运维流程
- **依赖风险**：B站/YouTube 嵌入受网络环境影响 → 视频页提供原始链接作为降级方案
- **进度风险**：富文本编辑器与 Next.js 集成可能有 SSR 兼容问题 → 使用 `dynamic import` 解决
